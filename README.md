# Turismo Inteligente Sustentable para México

Este repositorio contiene el desarrollo del **Problema Prototípico de 5to Semestre** de la Licenciatura en Ciencias de Datos para Negocios.

## Objetivo
Diseñar una campaña publicitaria inteligente, estratégica y sustentable para un destino turístico en México. El objetivo principal es promover una distribución equilibrada de los flujos turísticos, mitigando la saturación de ciertos destinos y apoyando el desarrollo económico en áreas menos concurridas, sin comprometer los ecosistemas locales y la calidad de vida de los residentes.

## Estructura del Proyecto
- **PLAN_DE_ACCION.md**: Contiene el cronograma y las fases detalladas del proyecto.
- *(Próximamente)* **datos/**: Bases de datos y diccionarios de datos.
- *(Próximamente)* **notebooks/**: Scripts y notebooks de Minería de Datos, Machine Learning y simulaciones.
- *(Próximamente)* **docs/**: Informe técnico final y documentación.
- *(Próximamente)* **campaña/**: Recursos y piezas de la campaña publicitaria digital.

## Materias Integradas (UCAs)
1. Herramientas para el Almacenamiento de Grandes Volúmenes de Datos
2. Minería de Datos
3. Aprendizaje de Máquina
4. Modelos Estocásticos para la Toma de Decisiones
5. Investigación de Operaciones
6. Mercadotecnia Digital
